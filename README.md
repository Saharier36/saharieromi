## ✨ Key Features

- 🎨 **3D WebGL Ribbon Background**: Immersive procedural ribbon mesh canvas rendered via OGL shaders.
- ⚡ **Next.js 16 & React 19 Architecture**: Built leveraging the App Router for optimal server component performance, SEO, and fast routing.
- 💎 **Glassmorphism & Micro-Interactions**: Bespoke specular buttons, spotlight cards, border glow, text shuffle animations, and interactive skill chips.
- 🌗 **Dark & Light Mode Integration**: Built-in theme toggler using `next-themes` with seamless CSS variable transitions.
- 📱 **Fully Responsive Layout**: Designed mobile-first, ensuring fluid scaling across smart devices, tablets, and wide monitors.
- 📁 **Comprehensive Portfolio Sections**:
  - **Hero**: Rotating title roles with interactive call-to-action buttons.
  - **About**: Personal profile overview and key strengths.
  - **Projects**: Filterable project showcases complete with tech badges, live links, and GitHub links.
  - **Experience**: Timeline of professional work history.
  - **Education & Certifications**: Academic background and credentials.
  - **Skills**: Interactive skill chips categorized by domain.
  - **Contact**: Fully functional interactive contact form powered by **Web3Forms** with real-time `sonner` toast notifications.
- 🚨 **Custom UX & Error Fallbacks**: Custom 404 Not Found page, interactive Canvas 500 error recovery page, and minimal loading spinners.

## 🚀 Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: v18.0.0 or higher
- **npm**, **yarn**, or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saharier36/saharieromi.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory based on `.env.example`:
   ```bash
   cp .env.example .env.local
   ```
   Add your Web3Forms access key:
   ```env
   NEXT_PUBLIC_WEB3FORMS_KEY=your_access_key_here
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **View in browser:**  
   Open [http://localhost:3000](http://localhost:3000) in your web browser to see the live application.
