# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-23

### Added
- Initial release of the Next.js personal portfolio web application.
- Immersive 3D WebGL ribbon background shaders (via OGL).
- Modern responsive layout built with Next.js 16 App Router, React 19, and Tailwind CSS v4.
- Custom canvas-based `FuzzyText` animations for interactive text effects.
- Custom branded error and fallback pages (`not-found.tsx` for 404 and `error.tsx` for 500) with responsive scaling and accent/error color themes.
- Global minimalistic `loading.tsx` screen with a custom Shadcn-compatible spinner.
- Fully functional interactive contact form powered by Web3Forms with real-time Sonner toast notifications.
- Dark and light mode integration using `next-themes`.
- Comprehensive documentation including `README.md`, `CLAUDE.md`, `.env.example`, and an MIT License.
